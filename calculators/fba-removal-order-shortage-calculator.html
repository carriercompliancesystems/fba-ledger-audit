Calculation method

How to read the result

Subtract physically received and other accounted-for units from the requested quantity. Use mutually exclusive counts so a package still in transit is counted only once. The remaining value is an inventory exposure estimate.

Worked example

An 80-unit order with 61 received and 12 otherwise accounted for leaves seven unexplained units. At $15 each, that is $105 of inventory to trace.

Seller questions

Common questions

What belongs in other accounted-for units?

Enter units you can explain through a pending package, cancellation or another documented outcome. Exclude units already counted as physically received.

Which records should I compare?

Match the removal order identifier, tracking, package counts and receiving record. Verify the current support category and applicable timing before opening a case.

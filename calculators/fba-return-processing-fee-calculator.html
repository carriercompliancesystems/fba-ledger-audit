Calculation method

How to read the result

Multiply the confirmed fee-bearing returns by your applicable per-return rate. Subtract that modeled charge from the amount billed. Split the calculation if different units face different rates.

Worked example

Twelve assessed returns at an illustrative $2.50 total $30. If the matching statement shows $36, the $6 difference is worth tracing.

Seller questions

Common questions

Should every refunded order be counted?

Enter the number you confirmed qualifies for the processing fee. A customer refund and a fee-bearing physical return represent different events.

How do I handle multiple rates in one period?

Group returns by the applicable rate, run each group separately, and compare against the corresponding statement charges.
